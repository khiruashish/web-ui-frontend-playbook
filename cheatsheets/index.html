    Cheat Sheets¶

    Dense, scannable references for when you already know the concept and just need the syntax. Each sheet links back to the full chapter for explanations.

    • HTML

      Page skeleton, every element by purpose, "which element should I use?", meta/link, script loading, forms, all 22 input types, global attributes, ARIA, entities.

    • CSS

      Syntax, every selector, pseudo-classes and elements, cascade and specificity, box model, display, positioning, typography, backgrounds, at-rules, a modern reset.

    • CSS3 & Modern CSS

      Visual cards for radius, shadows, gradients, filters, blend modes and transforms. Transitions, animations, and every 2020–2026 feature with its Baseline status.

    • Flexbox

      60 live mini-diagrams: every container and item property value, everyday recipes, property table, gotchas.

    • Grid

      50+ live mini-diagrams: columns, rows, auto-fit/auto-fill, placement, named areas, alignment, layout recipes, gotchas.

    • Responsive

      Breakpoints, media query syntax, every media feature, container queries, intrinsic layouts, fluid type, responsive images, mobile viewport units.

    • Units, Colours & Functions

      Every unit, every colour format, contrast targets, maths functions, fluid formulas, easing presets, duration guide.

    • UI Components & Patterns

      30+ components with the right HTML, key CSS and keyboard rules. Layout one-liners, design tokens, colour roles, a11y and performance checklists, current UI styles.

    Also useful¶

    • A–Z Tag Reference: every HTML element with one line each
    • CSS Property Cheat Sheet: ~200 properties grouped by job, with inheritance
    • Flexbox interview cheat sheet and Grid cheat sheet

    Printing

    Every cheat sheet prints cleanly: the header, navigation and sidebars are hidden and the visual cards are laid out four per row. Use your browser's Print → Save as PDF to keep an offline copy.
