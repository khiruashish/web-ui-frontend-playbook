    5. Loops & Array Methods¶

    Beginner Intermediate

    A loop repeats code: for every product, for every cart item, until stock runs out. Modern JavaScript mostly uses for…of and array methods (map, filter, reduce) instead of counting by hand.

    The classic for loop¶

    // Classic for: start; keep going while; step
for (let i = 1; i <= 3; i++) {
  console.log(`Slot ${i}: ${6 + i}:00`);
}
    Console output
    Slot 1: 7:00
Slot 2: 8:00
Slot 3: 9:00
    Part What it does
    let i = 1; Runs once, before the loop starts: create a counter.
    i <= 3; Checked before every round. When it's false, the loop ends.
    i++ Runs after every round: add 1 to the counter.
    { … } The body: runs once per round.

    Use it when you need a counter. To go through an array, prefer for…of.

    for…of: each value in a list¶

    const basket = ["Apple", "Milk", "Bread"];

for (const item of basket) {           // for…of: each VALUE of an array (or string, Map, Set)
  console.log("Packing", item);
}

for (const [index, item] of basket.entries()) {   // when you also need the position
  console.log(index + 1, item);
}

const stock = { apple: 12, milk: 0 };
for (const [id, qty] of Object.entries(stock)) {  // loop over an object's key/value pairs
  console.log(id, qty > 0 ? "in stock" : "sold out");
}
    Console output
    Packing Apple
Packing Milk
Packing Bread
1 Apple
2 Milk
3 Bread
apple in stock
milk sold out
    Code What it does
    for (const item of basket) Each round, item is the next value. No index maths, no off-by-one errors.
    basket.entries() + [index, item] When you also need the position.
    Object.entries(stock) Turns an object into [key, value] pairs so you can loop over it.

    for…in is different

    for (const key in obj) loops over an object's keys, and on an array it gives you the indexes as strings. Use for…of for arrays and Object.entries() for objects.

    while, break and continue¶

    let stockLeft = 5;
let orders = 0;
while (stockLeft >= 2) {               // repeat while the condition is true
  stockLeft -= 2;
  orders++;
}
console.log(`${orders} orders of 2, ${stockLeft} left`);

for (const n of [3, 8, 1, 9]) {
  if (n === 1) continue;              // skip this one, go to the next
  if (n === 9) break;                 // stop the loop completely
  console.log(n);
}
    Console output
    2 orders of 2, 1 left
3
8
    Code What it does
    while (stockLeft >= 2) { … } Repeats as long as the condition is true. Make sure something in the body eventually makes it false, or the page freezes.
    continue Skip the rest of this round and go to the next one.
    break Leave the loop completely.

    Array methods: say what, not how¶

    These take a callback (lesson 3) and call it once for every item.

    const products = [
  { name: "Shimla Apple", pricePaise: 18900, category: "fruits", deal: true },
  { name: "Robusta Banana", pricePaise: 4900, category: "fruits", deal: false },
  { name: "Fresh Tomato", pricePaise: 3200, category: "vegetables", deal: true },
  { name: "Full Cream Milk", pricePaise: 6800, category: "dairy", deal: false },
  { name: "Brown Eggs", pricePaise: 8400, category: "dairy", deal: true },
];

// map: turn every item into something else (same length)
const names = products.map((p) => p.name);
console.log(names);

// filter: keep only the items that pass a test
const dairy = products.filter((p) => p.category === "dairy");
console.log(dairy.map((p) => p.name));

// find: the FIRST item that passes, or undefined
console.log(products.find((p) => p.pricePaise < 5000));

// some / every: does any / do all pass?
console.log(products.some((p) => p.deal), products.every((p) => p.deal));

// reduce: boil the whole array down to one value
const total = products.reduce((sum, p) => sum + p.pricePaise, 0);
console.log(total);

// chain them: names of discounted items under ₹100, cheapest first
const cheapDeals = products
  .filter((p) => p.deal && p.pricePaise < 10000)
  .toSorted((a, b) => a.pricePaise - b.pricePaise)
  .map((p) => `${p.name} ₹${p.pricePaise / 100}`);
console.log(cheapDeals);
    Console output
    [
  'Shimla Apple',
  'Robusta Banana',
  'Fresh Tomato',
  'Full Cream Milk',
  'Brown Eggs'
]
[ 'Full Cream Milk', 'Brown Eggs' ]
{
  name: 'Robusta Banana',
  pricePaise: 4900,
  category: 'fruits',
  deal: false
}
true false
42200
[ 'Fresh Tomato ₹32', 'Brown Eggs ₹84' ]
    Method Returns Use it to…
    .map((p) => p.name) A new array, same length Turn every item into something else (objects → names, data → <li> elements).
    .filter((p) => p.category === "dairy") A new array, maybe shorter Keep only the items that pass a test.
    .find((p) => p.pricePaise < 5000) One item, or undefined Get the first match. (.findIndex gives its position.)
    .some(…) / .every(…) true / false "Is there at least one…?" / "Are all of them…?"
    .reduce((sum, p) => sum + p.pricePaise, 0) One value Add up or combine everything. sum starts at 0 and carries the running result.
    chained .filter().toSorted().map() Each method returns a new array, so you can line them up like a pipeline. Read it top to bottom.

    map, filter, find, some, every and reduce never change the original array.

    How reduce works, step by step¶

    Round sum (before) p.pricePaise returns
    1 0 (the start value) 18900 18900
    2 18900 4900 23800
    3 23800 3200 27000
    4 27000 6800 33800
    5 33800 8400 42200

    Sorting¶

    const prices = [4900, 18900, 3200, 6800];

console.log([...prices].sort());                   // default sort compares as TEXT
console.log([...prices].sort((a, b) => a - b));    // numbers, low → high
console.log([...prices].sort((a, b) => b - a));    // high → low
console.log(prices.toSorted((a, b) => a - b));     // toSorted() returns a new array
console.log(prices);                               // the original was never changed

const names = ["banana", "Apple", "cherry"];
console.log(names.toSorted((a, b) => a.localeCompare(b)));   // alphabetical, ignoring case
    Console output
    [ 18900, 3200, 4900, 6800 ]
[ 3200, 4900, 6800, 18900 ]
[ 18900, 6800, 4900, 3200 ]
[ 3200, 4900, 6800, 18900 ]
[ 4900, 18900, 3200, 6800 ]
[ 'Apple', 'banana', 'cherry' ]
    Code What it does
    .sort() with no function Compares items as text, so "18900" comes before "3200" (because "1" < "3"). Always pass a compare function for numbers.
    (a, b) => a - b A negative result puts a first. Low → high. Swap to b - a for high → low.
    .sort() vs .toSorted() sort() changes the original array. toSorted() returns a sorted copy. Prefer toSorted(), or [...arr].sort().
    a.localeCompare(b) Correct alphabetical order for words, ignoring case and handling accents.

    Grouping¶

    const items = [
  { name: "Apple", category: "fruits" },
  { name: "Milk", category: "dairy" },
  { name: "Banana", category: "fruits" },
];
const byCategory = Object.groupBy(items, (item) => item.category);
console.log(byCategory.fruits.map((i) => i.name));
console.log(Object.keys(byCategory));
    Console output
    [ 'Apple', 'Banana' ]
[ 'fruits', 'dairy' ]

    Object.groupBy(items, callback) puts items into buckets by whatever the callback returns: perfect for "products by category" sections. (Supported in all current browsers since 2024.)

    Putting it together: a cart bill¶

    // Putting it together: the bill for a cart
const catalogue = new Map([
  ["apple", { name: "Shimla Apple", pricePaise: 18900 }],
  ["milk", { name: "Full Cream Milk", pricePaise: 6800 }],
  ["bread", { name: "Whole Wheat Bread", pricePaise: 5000 }],
]);
const cart = [
  { id: "apple", qty: 2 },
  { id: "bread", qty: 1 },
];

const lines = cart.map(({ id, qty }) => {
  const { name, pricePaise } = catalogue.get(id);
  return { name, qty, linePaise: pricePaise * qty };
});
const subtotal = lines.reduce((sum, line) => sum + line.linePaise, 0);
const delivery = subtotal >= 19900 ? 0 : 2500;

const rupees = (paise) => `₹${(paise / 100).toFixed(2)}`;
for (const line of lines) console.log(`${line.name.padEnd(18)} × ${line.qty}  ${rupees(line.linePaise)}`);
console.log(`Delivery: ${delivery ? rupees(delivery) : "FREE"}`);
console.log(`To pay:   ${rupees(subtotal + delivery)}`);
    Console output
    Shimla Apple       × 2  ₹378.00
Whole Wheat Bread  × 1  ₹50.00
Delivery: FREE
To pay:   ₹428.00
    Code What it does
    new Map([[id, product], …]) A catalogue to look products up by id.
    cart.map(({ id, qty }) => { … }) For each cart line: destructure, look up the product, return a line with its total.
    lines.reduce((sum, line) => sum + line.linePaise, 0) Add all the line totals.
    subtotal >= 19900 ? 0 : 2500 Free delivery from ₹199.
    `${line.name.padEnd(18)} …` padEnd lines up the columns.

    This is the same logic as the FreshCart cart drawer in E-commerce lesson 6.

    Try it¶

    1. From the products array, make an array of strings like "Shimla Apple: ₹189" with map.
    2. Count how many products are deals with filter(...).length, then do it again with reduce.
    3. Sort the products by name, A to Z, without changing the original array.
    4. Find the most expensive product with reduce (hint: keep the bigger of best and p each round).

    Solutions¶

    Try each exercise yourself first, then open its solution to compare.

    1. Labels with map 
    const products = [
  { name: "Shimla Apple", pricePaise: 18900, category: "fruits", deal: true },
  { name: "Robusta Banana", pricePaise: 4900, category: "fruits", deal: false },
  { name: "Fresh Tomato", pricePaise: 3200, category: "vegetables", deal: true },
  { name: "Full Cream Milk", pricePaise: 6800, category: "dairy", deal: false },
  { name: "Brown Eggs", pricePaise: 8400, category: "dairy", deal: true },
];

const labels = products.map((p) => `${p.name}: ₹${p.pricePaise / 100}`);
console.log(labels);
    Console output
    [
  'Shimla Apple: ₹189',
  'Robusta Banana: ₹49',
  'Fresh Tomato: ₹32',
  'Full Cream Milk: ₹68',
  'Brown Eggs: ₹84'
]
    2. Counting deals two ways 
    const products = [
  { name: "Shimla Apple", deal: true },
  { name: "Robusta Banana", deal: false },
  { name: "Fresh Tomato", deal: true },
  { name: "Full Cream Milk", deal: false },
  { name: "Brown Eggs", deal: true },
];

console.log(products.filter((p) => p.deal).length);
console.log(products.reduce((count, p) => (p.deal ? count + 1 : count), 0));
    Console output
    3
3

    filter(...).length is easier to read; reduce avoids building a temporary array, which only matters for very large lists.

    3. Sort by name without changing the original 
    const products = [
  { name: "Shimla Apple" },
  { name: "Robusta Banana" },
  { name: "Fresh Tomato" },
  { name: "Full Cream Milk" },
  { name: "Brown Eggs" },
];

const byName = products.toSorted((a, b) => a.name.localeCompare(b.name));
console.log(byName.map((p) => p.name));
console.log(products[0].name);   // the original order is untouched
    Console output
    [
  'Brown Eggs',
  'Fresh Tomato',
  'Full Cream Milk',
  'Robusta Banana',
  'Shimla Apple'
]
Shimla Apple
    4. Most expensive with reduce 
    const products = [
  { name: "Robusta Banana", pricePaise: 4900 },
  { name: "Shimla Apple", pricePaise: 18900 },
  { name: "Fresh Tomato", pricePaise: 3200 },
  { name: "Brown Eggs", pricePaise: 8400 },
];

const mostExpensive = products.reduce((best, p) => (p.pricePaise > best.pricePaise ? p : best));
console.log(mostExpensive.name);
    Console output
    Shimla Apple

    With no start value, reduce uses the first item as best and starts from the second. That's fine here, but it throws a TypeError on an empty array, so check products.length first in real code.

    Common mistakes¶

    • .sort() on numbers without a compare function.
    • Using map just to loop (ignoring the array it returns). Use for…of or forEach for side effects.
    • Forgetting the start value in reduce (0): on an empty array it throws an error.
    • Changing the array while looping over it. Build a new one with filter instead.
