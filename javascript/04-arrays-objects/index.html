    4. Arrays & Objects¶

    Beginner Intermediate

    Real data comes in groups: a list of products, a product with a name, price and size. Arrays hold lists; objects hold named fields. Almost every API returns an array of objects.

    Arrays: ordered lists¶

    const fruits = ["Apple", "Banana", "Mango"];

console.log(fruits[0]);              // positions (indexes) start at 0
console.log(fruits.length);
console.log(fruits.at(-1));          // last item

fruits.push("Grapes");               // add at the end
console.log(fruits);

const removed = fruits.shift();      // remove from the start
console.log(removed, fruits);

console.log(fruits.includes("Mango"));
console.log(fruits.indexOf("Grapes"));
console.log(fruits.join(" · "));
    Console output
    Apple
3
Mango
[ 'Apple', 'Banana', 'Mango', 'Grapes' ]
Apple [ 'Banana', 'Mango', 'Grapes' ]
true
2
Banana · Mango · Grapes
    Code What it does
    ["Apple", "Banana", "Mango"] An array literal: values in [ ], separated by commas.
    fruits[0] The first item. Positions (indexes) start at 0, so the last is fruits[fruits.length - 1].
    fruits.at(-1) Negative positions count from the end: the easy way to get the last item.
    fruits.push("Grapes") Adds to the end. (unshift adds to the start.)
    fruits.shift() Removes and returns the first item. (pop removes the last.)
    .includes(…), .indexOf(…) "Is it there?" and "at which position?" (-1 if not found).
    .join(" · ") Joins all items into one string with a separator.

    const fruits doesn't stop you changing the array's contents; it only stops you pointing fruits at a different array.

    Objects: named fields¶

    const product = {
  id: "apple",
  name: "Shimla Apple",
  pricePaise: 18900,
  inStock: true,
  tags: ["fruit", "seasonal"],
};

console.log(product.name);           // dot notation
console.log(product["pricePaise"]);  // bracket notation (needed when the key is in a variable)

const key = "inStock";
console.log(product[key]);

product.pricePaise = 17900;          // change a property
product.rating = 4.6;                // add a new one
delete product.tags;                 // remove one
console.log(product);

console.log(Object.keys(product));
console.log("rating" in product);
    Console output
    Shimla Apple
18900
true
{
  id: 'apple',
  name: 'Shimla Apple',
  pricePaise: 17900,
  inStock: true,
  rating: 4.6
}
[ 'id', 'name', 'pricePaise', 'inStock', 'rating' ]
true
    Code What it does
    { id: "apple", name: "Shimla Apple", … } An object literal: key: value pairs. Keys are names; values can be anything, including arrays and other objects.
    product.name Dot notation: read a property.
    product["pricePaise"], product[key] Bracket notation: needed when the key is in a variable or has spaces/dashes.
    product.pricePaise = 17900; Change a property.
    product.rating = 4.6; Assigning to a key that doesn't exist adds it.
    delete product.tags; Removes a property.
    Object.keys(product) An array of the keys. (Object.values and Object.entries exist too.)
    "rating" in product Does the key exist?

    An array of objects¶

    // The shape almost every API returns: an array of objects
const products = [
  { id: "apple", name: "Shimla Apple", pricePaise: 18900, category: "fruits" },
  { id: "milk", name: "Full Cream Milk", pricePaise: 6800, category: "dairy" },
  { id: "bread", name: "Whole Wheat Bread", pricePaise: 5000, category: "bakery" },
];

console.log(products.length, "products");
console.log(products[1].name);
console.log(products[2].pricePaise / 100);
    Console output
    3 products
Full Cream Milk
50

    products[1].name reads left to right: "the array → item at position 1 → its name". Lesson 5 shows how to loop over, filter and total arrays like this one.

    Destructuring: unpack values into variables¶

    const item = { name: "Brown Eggs", pricePaise: 8400, size: "6 pcs" };

const { name, pricePaise } = item;           // pull properties out into variables
console.log(name, pricePaise);

const { size: packSize, rating = "no rating" } = item;   // rename, and give a default
console.log(packSize, rating);

const [first, second] = ["Apple", "Banana", "Mango"];    // arrays: by position
console.log(first, second);

function describe({ name, size }) {           // destructuring right in the parameters
  return `${name} (${size})`;
}
console.log(describe(item));
    Console output
    Brown Eggs 8400
6 pcs no rating
Apple Banana
Brown Eggs (6 pcs)
    Code What it does
    const { name, pricePaise } = item; Creates two variables from the properties with the same names. Same as const name = item.name; const pricePaise = item.pricePaise;
    { size: packSize } Read size, but call the variable packSize.
    { rating = "no rating" } A default when the property is missing.
    const [first, second] = [...] Arrays destructure by position.
    function describe({ name, size }) Destructure right in the parameter list: very common in frameworks.

    Spread: copy and combine¶

    const base = { name: "Milk", pricePaise: 6800 };

const updated = { ...base, pricePaise: 7200 };   // copy, then override one property
console.log(base);                               // the original is unchanged
console.log(updated);

const veg = ["Tomato", "Onion"];
const fruit = ["Apple"];
const all = [...veg, ...fruit, "Bread"];         // join arrays
console.log(all);
    Console output
    { name: 'Milk', pricePaise: 6800 }
{ name: 'Milk', pricePaise: 7200 }
[ 'Tomato', 'Onion', 'Apple', 'Bread' ]
    Code What it does
    { ...base, pricePaise: 7200 } Copies every property of base into a new object, then overrides pricePaise. The original stays unchanged.
    [...veg, ...fruit, "Bread"] Spreads both arrays' items into a new array.

    This "copy, don't change" style is how React, Angular signals and most state libraries expect you to update data.

    References: two names, one object¶

    // Objects and arrays are shared by reference, not copied
const cartA = ["Apple"];
const cartB = cartA;          // the SAME array, two names
cartB.push("Milk");
console.log(cartA);

const cartC = [...cartA];     // a real (shallow) copy
cartC.push("Bread");
console.log(cartA, cartC);

console.log([1, 2] === [1, 2]);   // two different arrays, even with equal contents
    Console output
    [ 'Apple', 'Milk' ]
[ 'Apple', 'Milk' ] [ 'Apple', 'Milk', 'Bread' ]
false
    Code What it does
    const cartB = cartA; Does not copy. Both names point to the same array, so pushing through cartB changes what cartA sees.
    const cartC = [...cartA]; A real copy (one level deep: objects inside it are still shared; use structuredClone() for a full copy).
    [1, 2] === [1, 2] → false === on objects asks "the same object?", not "the same contents?"

    Map and Set¶

    // Map: key → value, with any type of key, and easy to loop over
const cart = new Map();
cart.set("apple", 2);
cart.set("milk", 1);
cart.set("apple", 3);                 // same key: replaces the value
console.log(cart.get("apple"), cart.size, cart.has("bread"));
for (const [id, qty] of cart) console.log(id, "×", qty);

// Set: a list with no duplicates
const tags = new Set(["fruit", "organic", "fruit"]);
tags.add("seasonal");
console.log(tags.size, [...tags]);
    Console output
    3 2 false
apple × 3
milk × 1
3 [ 'fruit', 'organic', 'seasonal' ]
    Code What it does
    new Map() A key → value store. Great for a cart: product id → quantity.
    .set(key, value) / .get(key) / .has(key) / .delete(key) / .size Add or replace, read, check, remove, count.
    for (const [id, qty] of cart) Loops over [key, value] pairs in the order they were added.
    new Set([...]) A collection with no duplicates: the second "fruit" is ignored.
    [...tags] Turn a Set (or Map) into an array.

    Use a plain object for a fixed record (product.name); use a Map for a changing lookup table.

    JSON: data as text¶

    // JSON is how data travels between server and browser: always text
const order = { id: 1042, items: [{ id: "apple", qty: 2 }], paid: false };

const text = JSON.stringify(order);
console.log(text);
console.log(typeof text);

const back = JSON.parse(text);
console.log(back.items[0].qty);

console.log(JSON.stringify(order, null, 2));     // pretty-printed, 2-space indent
    Console output
    {"id":1042,"items":[{"id":"apple","qty":2}],"paid":false}
string
2
{
  "id": 1042,
  "items": [
    {
      "id": "apple",
      "qty": 2
    }
  ],
  "paid": false
}
    Code What it does
    JSON.stringify(order) Object → JSON string, ready to send to a server or save in localStorage.
    JSON.parse(text) JSON string → a new object you can use again.
    JSON.stringify(order, null, 2) Pretty-printed with 2-space indentation: handy for debugging.

    JSON looks like JavaScript but is stricter: keys and strings need double quotes, and there are no comments, functions or undefined.

    Try it¶

    1. Create an array of 3 product objects (name, pricePaise, category). Print the name of the second one and the category of the last one using .at(-1).
    2. Write withPrice(product, newPaise) that returns a new product object with the changed price, using spread. Check the original is unchanged.
    3. Save a Map cart to a JSON string and load it back: JSON.stringify([...cart]) and new Map(JSON.parse(text)).

    Solutions¶

    Try each exercise yourself first, then open its solution to compare.

    1. Second name, last category 
    const products = [
  { name: "Shimla Apple", pricePaise: 18900, category: "fruits" },
  { name: "Full Cream Milk", pricePaise: 6800, category: "dairy" },
  { name: "Whole Wheat Bread", pricePaise: 5000, category: "bakery" },
];

console.log(products[1].name);
console.log(products.at(-1).category);
    Console output
    Full Cream Milk
bakery
    2. withPrice with spread 
    function withPrice(product, newPaise) {
  return { ...product, pricePaise: newPaise };
}

const milk = { name: "Full Cream Milk", pricePaise: 6800 };
const dearerMilk = withPrice(milk, 7200);

console.log(milk);          // unchanged
console.log(dearerMilk);    // a new object
console.log(milk === dearerMilk);
    Console output
    { name: 'Full Cream Milk', pricePaise: 6800 }
{ name: 'Full Cream Milk', pricePaise: 7200 }
false

    The original keeps ₹68 and the two are different objects. Code that receives a product can't be surprised by it changing later.

    3. Map → JSON → Map 
    const cart = new Map([
  ["apple", 2],
  ["milk", 1],
]);

const text = JSON.stringify([...cart]);   // a Map can't be stringified directly; turn it into [key, value] pairs first
console.log(text);

const loaded = new Map(JSON.parse(text)); // pairs → Map again
console.log(loaded.get("apple"), loaded.size);
    Console output
    [["apple",2],["milk",1]]
2 2

    JSON.stringify(cart) on the Map itself would give "{}": Maps aren't plain objects. Spreading turns it into an array of [key, value] pairs, which JSON can hold, and new Map(pairs) turns it back. FreshCart uses exactly this to keep the cart after a refresh.

    Common mistakes¶

    • fruits[3] on a 3-item array: indexes start at 0, so it's undefined.
    • Thinking const b = a copies an array or object. It doesn't.
    • Changing an object you received as a parameter and accidentally changing the caller's data. Return a copy instead.
    • Comparing objects with === to check if they have the same contents.
