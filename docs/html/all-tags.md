## `<math>` MathML <span class="lvl lvl-3">Advanced</span> { #math-mathml data-toc-label="&lt;math&gt; MathML" }

MathML Core is supported in all major browsers since 2023.

```html
<math display="block">
  <mi>x</mi><mo>=</mo>
  <mfrac>
    <mrow><mo>−</mo><mi>b</mi><mo>±</mo>
      <msqrt><msup><mi>b</mi><mn>2</mn></msup><mo>−</mo><mn>4</mn><mi>a</mi><mi>c</mi></msqrt>
    </mrow>
    <mrow><mn>2</mn><mi>a</mi></mrow>
  </mfrac>
</math>
```

## Deprecated and obsolete tags: use this instead

You'll find these in old code. Browsers may still render some of them, but they're not valid HTML.

| Obsolete tag | What it did | Use instead |
|---|---|---|
| `<center>` | Centred content | CSS `text-align: center` or `margin-inline: auto` / flex / grid |
| `<font>` | Font face, size, colour | CSS `font-family`, `font-size`, `color` |
| `<big>` | Bigger text | CSS `font-size` |
| `<tt>` | Teletype (monospace) | `<code>`, `<kbd>`, `<samp>` or CSS `font-family: monospace` |
| `<strike>` | Strikethrough | `<s>` or `<del>` |
| `<acronym>` | Acronym | `<abbr>` |
| `<marquee>` | Scrolling text | CSS animation (and respect reduced motion), or better, don't |
| `<blink>` | Blinking text | Don't (fails WCAG 2.2.2) |
| `<frame>`, `<frameset>`, `<noframes>` | Split the window into frames | CSS Grid layouts, `<iframe>` |
| `<applet>` | Java applets | `<object>`, `<canvas>`, WebAssembly |
| `<basefont>` | Default font | CSS on `body` |
| `<dir>` | Directory list | `<ul>` |
| `<isindex>` | Search field | `<form>` + `<input type="search">` |
| `<listing>`, `<xmp>`, `<plaintext>` | Preformatted text | `<pre>` + `<code>` |
| `<nobr>` | No line breaks | CSS `white-space: nowrap` |
| `<spacer>` | Whitespace | CSS `margin` / `gap` |
| `<param>` | Parameters for `<object>` (removed 2023) | `data` attributes on `<object>` |
| `<keygen>` | Key-pair generator | Web Crypto API |
| `<rb>`, `<rtc>` | Ruby base / text container | `<ruby>` + `<rt>` |
| `<image>` | Typo alias for img | `<img>` |
| `<menuitem>` | Context menu item | `<button>` inside `<menu>` |

Obsolete **attributes** to replace with CSS: `align`, `bgcolor`, `border` (on img/table), `cellpadding`, `cellspacing`, `valign`, `width`/`height` on table cells, `hspace`/`vspace`, `frameborder`, `scrolling`.
