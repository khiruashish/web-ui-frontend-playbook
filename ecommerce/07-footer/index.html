    7. Footer & Mobile Bottom Nav¶

    Beginner Intermediate

    The footer holds everything people look for when they're stuck: company links, help, a newsletter signup and legal text. Shopping apps also add a bottom navigation bar on phones, because the bottom of the screen is where thumbs reach.

    What you see¶

    Open it full-size: 07-footer.html and make the window narrow: the footer columns stack and the bottom nav appears.

    ⑬ Footer: HTML¶

    <footer class="site-footer">
  <div class="container">
    <div class="footer-grid">
      <section>
        <h2>FreshCart</h2>
        <p>Groceries from local farms, delivered in minutes. Open 6 am to midnight, every day.</p>
      </section>
      <nav aria-label="Company">
        <h2>Company</h2>
        <ul>
          <li><a href="#">About us</a></li>
          <li><a href="#">Careers</a></li>
          <li><a href="#">Blog</a></li>
        </ul>
      </nav>
      <nav aria-label="Help">
        <h2>Help</h2>
        <ul>
          <li><a href="#">FAQs</a></li>
          <li><a href="#">Track order</a></li>
          <li><a href="#">Contact us</a></li>
        </ul>
      </nav>
      <section>
        <h2>Get offers by email</h2>
        <form class="newsletter" action="#">
          <label class="visually-hidden" for="email">Email address</label>
          <input id="email" type="email" placeholder="you@example.com" autocomplete="email" required>
          <button class="btn" type="submit">Subscribe</button>
        </form>
      </section>
    </div>
    <div class="footer-bottom">
      <p>© 2026 FreshCart. A demo store for learning.</p>
      <p>We accept UPI · Cards · Cash on delivery</p>
    </div>
  </div>
</footer>
    Code What it does
    <footer class="site-footer"> The contentinfo landmark: the site-wide footer.
    <div class="container"> Same width as the rest of the page.
    <div class="footer-grid"> The grid of four columns.
    <section> + <h2>FreshCart</h2> + <p> Column 1: about the store.
    <nav aria-label="Company"> Columns 2 and 3 are groups of links, so they're <nav> elements, each with a different label so screen readers can tell them apart.
    <h2> inside each column Column headings. Footer headings are usually h2: they are top-level sections of the page.
    <ul> + <li><a> Links as lists, as always.
    <form class="newsletter" action="#"> Column 4: email signup.
    <label class="visually-hidden" for="email"> The design has no visible label, but the input still needs one.
    <input id="email" type="email" … autocomplete="email" required> type="email" shows the @ keyboard on phones and checks the format. autocomplete="email" lets the browser fill it in. required blocks an empty submit.
    <div class="footer-bottom"> The bottom strip: copyright and payment methods.

    Footer: CSS¶

    .site-footer {
  margin-top: var(--space-8);
  padding-top: var(--space-8);
  background: var(--text);
  color: #d5d9df;
  font-size: 0.9rem;
}
.footer-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(180px, 100%), 1fr));
  gap: var(--space-6);
}
.site-footer h2 {
  margin: 0 0 var(--space-3);
  font-size: 1rem;
  color: #fff;
}
.site-footer ul {
  margin: 0;
  padding: 0;
  list-style: none;
}
.site-footer li + li {
  margin-top: var(--space-2);
}
.site-footer a {
  text-decoration: none;
}
.site-footer a:hover {
  text-decoration: underline;
}
    Code What it does
    margin-top: var(--space-8); padding-top: var(--space-8); Space above the footer, and inside it.
    background: var(--text); color: #d5d9df; Dark footer with light-grey text. A dark footer clearly says "the page ends here".
    grid-template-columns: repeat(auto-fit, minmax(min(180px, 100%), 1fr)); Each column at least 180 px. Four columns on a desktop, two on a tablet, one on a phone, with no media queries. auto-fit (instead of auto-fill) stretches the columns to fill the row when there are fewer than fit.
    .site-footer h2 { font-size: 1rem; color: #fff; } Small white headings. The level is h2 for structure; the size is set by CSS.
    ul { margin: 0; padding: 0; list-style: none; } Plain list.
    li + li { margin-top: var(--space-2); } The + (adjacent sibling) selector: "an li that comes right after another li". Adds space between items but not above the first.
    a:hover { text-decoration: underline; } Underline on hover so it's clear these are links. 
    .newsletter {
  display: flex;
  gap: var(--space-2);
}
.newsletter input {
  flex: 1;
  min-width: 0;
  padding: var(--space-2) var(--space-3);
  border: 1px solid #4b5563;
  border-radius: var(--radius-sm);
  background: #111418;
  color: #fff;
}

.footer-bottom {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  gap: var(--space-2);
  margin-top: var(--space-8);
  padding-block: var(--space-4);
  border-top: 1px solid #3a404c;
  font-size: 0.8rem;
}
.footer-bottom p {
  margin: 0;
}
    Code What it does
    .newsletter { display: flex; gap: … } Input and button side by side.
    .newsletter input { flex: 1; min-width: 0; } The input takes the spare width and can shrink on narrow screens.
    background: #111418; color: #fff; border: 1px solid #4b5563; A dark input that fits the dark footer.
    .footer-bottom { display: flex; flex-wrap: wrap; justify-content: space-between; } Copyright left, payments right; they wrap onto two lines on phones.
    border-top: 1px solid #3a404c; A subtle divider above the bottom strip.

    ⑮ Mobile bottom nav¶

    <nav class="bottom-nav" aria-label="Mobile">
  <a href="#" aria-current="page"><span aria-hidden="true">🏠</span>Home</a>
  <a href="#"><span aria-hidden="true">🗂️</span>Categories</a>
  <a href="#" data-open-cart><span aria-hidden="true">🛒</span>Cart</a>
  <a href="#"><span aria-hidden="true">👤</span>Account</a>
</nav>

    .bottom-nav {
  position: fixed;
  inset: auto 0 0 0;
  z-index: 10;
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  background: var(--surface);
  border-top: 1px solid var(--line);
  padding-bottom: env(safe-area-inset-bottom);
}
.bottom-nav a {
  display: flex;
  flex-direction: column;
  align-items: center;
  padding: var(--space-2) 0;
  font-size: 0.7rem;
  text-decoration: none;
}
.bottom-nav span {
  font-size: 1.25rem;
}
.bottom-nav a[aria-current="page"] {
  color: var(--brand);
  font-weight: 700;
}
body:has(.bottom-nav) {
  padding-bottom: 64px;
}
@media (width >= 768px) {
  .bottom-nav {
    display: none;
  }
  body:has(.bottom-nav) {
    padding-bottom: 0;
  }
}
    Code What it does
    <nav class="bottom-nav" aria-label="Mobile"> A third navigation landmark, labelled.
    <a href="#" aria-current="page"> Home is the current page, so it's highlighted.
    <span aria-hidden="true">🏠</span>Home Icon above the word. The icon is decoration; the word is the link's name. Always keep a text label: icons alone are guessed wrong.
    <a href="#" data-open-cart> Opens the cart drawer (same hook as the header button, lesson 6).
    position: fixed; inset: auto 0 0 0; Fixed to the screen, not the page: it stays at the bottom while you scroll. inset is shorthand for top right bottom left: top: auto, and 0 from the right, bottom and left, so it spans the full width at the bottom.
    z-index: 10; Above the products.
    display: grid; grid-template-columns: repeat(4, 1fr); Four equal-width tabs.
    padding-bottom: env(safe-area-inset-bottom); On iPhones without a home button, adds space so the tabs aren't hidden under the home-indicator bar.
    .bottom-nav a { display: flex; flex-direction: column; align-items: center; } Icon above text, centred.
    a[aria-current="page"] { color: var(--brand); } Highlight the current tab, styled from the accessibility attribute.
    body:has(.bottom-nav) { padding-bottom: 64px; } :has() is the "parent selector": "the body, if it contains a bottom nav". The padding stops the fixed bar from covering the end of the footer.
    @media (width >= 768px) → display: none; and padding-bottom: 0 Desktops have the header links; no bottom bar needed.

    Try it¶

    1. Add a fifth tab "Offers 🔥" (hint: change repeat(4, 1fr)).
    2. Add social links (Instagram, X, YouTube) to column 1 as a row of icons with aria-labels.
    3. Make the footer columns collapsible on phones with <details>, like the filters in lesson 5.

    Solutions¶

    Try each exercise yourself first, then open its solution to compare.

    Every code solution below is applied in store-solved.html: the full store with all the exercises from every lesson done, tested in a real browser like the original. Its files are generated from store.html and store.js, so the snippets here are exactly what runs there.

    1. A fifth tab 
    <a href="#"><span aria-hidden="true">🔥</span>Offers</a>

    /* Lesson 7, exercise 1: five bottom-nav tabs */
.bottom-nav {
  grid-template-columns: repeat(5, 1fr);
}

    repeat(5, 1fr) gives five equal columns. Five is the practical maximum for a bottom bar: at 375 px each tab is 75 px wide, about the smallest comfortable tap target with a label.

    2. Social links 
    <ul class="social" aria-label="Follow us">
  <li><a href="#" aria-label="FreshCart on Instagram">📸</a></li>
  <li><a href="#" aria-label="FreshCart on X">✖️</a></li>
  <li><a href="#" aria-label="FreshCart on YouTube">▶️</a></li>
</ul>

    /* Lesson 7, exercise 2: round social icons in a row */
.site-footer .social {
  display: flex;
  gap: var(--space-2);
  margin-top: var(--space-4);   /* ".site-footer ul { margin: 0 }" is more specific than .social alone */
}
.site-footer .social li + li {
  margin-top: 0;
}
.social a {
  display: grid;
  place-items: center;
  width: 40px;
  height: 40px;
  border-radius: 50%;
  background: #2b3038;
  text-decoration: none;
}
.social a:hover {
  background: #3a404c;
}

    Icon-only links must have an aria-label, or a screen reader announces "link, camera emoji". The list gets its own label ("Follow us") so it reads as a group. .site-footer .social is needed because the footer's .site-footer ul { margin: 0 } is more specific than .social alone.

    3. Collapsible footer columns on phones

    Wrap each link column in a <details>, with the heading inside the <summary>:

    <nav aria-label="Company">
  <details class="footer-col" data-footer-col>
    <summary><h2>Company</h2></summary>
    <ul>
    <li><a href="#">About us</a></li>
    <li><a href="#">Careers</a></li>
      <li><a href="#">Blog</a></li>
    </ul>
  </details>
</nav>

    Open them on desktop with the same matchMedia trick as the filters:

    // Footer columns: collapsed <details> on phones, always open from 768 px (the same idea as the filters)
const footerColumns = document.querySelectorAll("[data-footer-col]");
const wide = window.matchMedia("(width >= 768px)");
const syncFooter = () => footerColumns.forEach((column) => (column.open = wide.matches));
syncFooter();
wide.addEventListener("change", syncFooter);

    And replace the default ▸ marker with a +/− on the right:

    /* Lesson 7, exercise 3: footer columns as <details> */
.footer-col summary {
  display: flex;
  justify-content: space-between;
  align-items: center;
  list-style: none;            /* hide the default ▸ marker… */
  cursor: pointer;
}
.footer-col summary::-webkit-details-marker {
  display: none;               /* …in Safari too */
}
.footer-col summary::after {
  content: "+";
  font-size: 1.25rem;
}
.footer-col[open] summary::after {
  content: "−";
}
@media (width >= 768px) {
  .footer-col summary {
    pointer-events: none;      /* always open on desktop: nothing to toggle */
  }
  .footer-col summary::after,
  .footer-col[open] summary::after {   /* list [open] too: it is more specific than the rule above */
    content: none;
  }
}

    On a phone the footer shrinks to two tappable rows instead of six links; on desktop nothing changes. Without JavaScript the columns still work, they just start closed.

    Common mistakes¶

    • Icon-only bottom navs. Users don't know what 🗂️ means; add the word.
    • Forgetting the body padding, so the bottom nav covers the copyright line and the last product.
    • Using <div> for each link group instead of <nav> + a heading: screen-reader users lose their way.
